# Maps Directions 0.1.0

Initial testing release for official Maps 0.2.2.

- Extend the existing Map layout with Directions and Connection style settings.
- Connect accepted Maps markers by a numeric sequence property, with optional route grouping.
- Draw lines and arrows below original markers without changing icons, colors or backgrounds.
- Keep processing local; no map engine or additional network service is bundled.
- Include capability checks, integration cleanup and a four-stop demo.

The addon relies on undocumented Maps/Bases internals. Future upstream updates
may require an adapter update. Mobile visual validation is pending.
